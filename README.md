# TinyPal Assignment (Frontend + Backend)

This repo contains a sample implementation for the TinyPal frontend screens (React Native / Expo) and a minimal backend (Express) that provides the required endpoints so you can run and test the app locally.

Folders:
- `frontend` - Expo React Native app with Did You Know and Flash Card screens and a Tinu bottom sheet.
- `backend` - Minimal Express server exposing `/p13n_answers` and `/activate_tinu` with sample data.

See each folder README for run instructions.
